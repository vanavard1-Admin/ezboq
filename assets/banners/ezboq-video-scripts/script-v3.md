# EzBOQ Reel Script v3 — Hook → Story → Tie-in

## Concept: "วันที่เอกสารมากกว่างาน"

### 🎬 HOOK (0-3s) — จับสายตาให้หยุดดู
**Video:** แมวผู้รับเหมาใส่หมวกเหลือง ตบกระดาษปลิวทั้งโต๊ะ จ้องกล้อง
**Text overlay (ตัวใหญ่):** "ช่างรับเหมา ดูนี่ก่อน!"
**Voice:** "ช่างรับเหมา! หยุดดูก่อน!"

### 🎬 STORY (3-10s) — เล่าเรื่อง pain point ให้คนเข้าใจ
**Video:** แมวนั่งท่ามกลางกองเอกสาร หน้าเครียด มองกระดาษงุนงง
**Text overlay (ขึ้นทีละอัน):**
- "ใบเสนอราคาพิมพ์ใหม่ทุกงาน"
- "ภาษีผิดบ่อย"
- "เอกสารกองเป็นตั้ง"
**Voice:** "ทุกวัน... ใบเสนอราคาพิมพ์ใหม่ทุกงาน ใบกำกับภาษีผิดบ่อย เอกสารกองเป็นตั้ง เสียเวลาทำเอกสารมากกว่าทำงานจริง"

### 🎬 TIE-IN (10-15s) — แนะนำ EzBOQ แบบธรรมชาติ
**Video:** แมวเดียวกัน นั่งหน้า laptop สบาย ยิ้ม โต๊ะสะอาด
**Text overlay:** "อีซี่บีโอคิว ทำเอกสารให้หมด ส่งผ่าน LINE เลย"
**Voice:** "จนมีคนบอกว่า ลองอีซี่บีโอคิว สร้างเอกสารครบใน 5 นาที ส่ง PDF ให้ลูกค้าผ่าน LINE ได้เลย ฟรีด้วย"

### 🎬 CTA (15-17s) — ปิดท้ายสั้นๆ
**Video:** Logo EzBOQ + แมวโบกมือ
**Text:** "ezboq.com — ฟรี!"
**Voice:** "อีซี่บีโอคิว ดอทคอม ครับ"
