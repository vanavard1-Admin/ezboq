## ✅ Flow การใช้งานเอกสาร (ถูกต้อง)

```
1. ใบเสนอราคาลูกค้า (Customer Quotation)
   ↓
2. ใบวางบิล (Invoice) + แผนการชำระเงิน
   ↓
3. แผนการทำงาน (Work Plan)
   ↓
4. ใบสั่งซื้อวัสดุ (Purchase Order) + สัญญารับเหมาก่อสร้าง
```
