## Phase 1: BOQ Templates ทุกประเภทงาน (เพิ่ม ~40 entries)

### 1.1 บ้านชั้นเดียว 120 ตร.ม. (~8 entries)
เหมือน BOQ บ้าน 2 ชั้นแต่ปรับตามจริง:
- โครงสร้าง: ฐานรากน้อยกว่า, ไม่มีเสายาว, ไม่มีคานชั้น 2
- หลังคา: พื้นที่มากกว่า (ไม่มีชั้น 2 บังลม)
- ระบบ: ท่อน้ำ/สายไฟสั้นกว่า, แอร์น้อยกว่า
- **งบประมาณ: ~1.2-1.8 ล้านบาท**

### 1.2 ต่อเติมบ้าน (~5 entries)
- ต่อห้อง 4x4 ม. (ห้องนอน/ห้องเก็บของ)
- ต่อครัว (เปียก+แห้ง)
- ต่อระเบียง/เฉลียง
- ต่อชั้น 2 (ต้องเสริมโครงสร้างเดิม!)
- **ข้อควรระวัง: รอยต่อโครงสร้างเก่า-ใหม่, waterproofing**

### 1.3 รีโนเวท (~6 entries)
- รีโนเวทห้องน้ำ (รื้อ→กันซึม→เดินท่อใหม่→ปู→สุขภัณฑ์)
- รีโนเวทครัว (ทุบ→ระบบ→ครัวใหม่)
- รีโนเวททั้งหลัง (แผนทำงานเป็น phase)
- เปลี่ยนหลังคา
- ทาสีใหม่ทั้งหลัง
- เปลี่ยนพื้น/กระเบื้อง

### 1.4 Interior / บิ้วอิน (~4 entries)
- ห้องนอน Master (walk-in closet + dresser + headboard)
- ห้องนั่งเล่น (TV wall + โซฟาบิ้วอิน + ชั้นวาง)
- ห้องทำงาน (โต๊ะบิ้วอิน + ชั้นหนังสือ + สายไฟ)
- คอนโด 30-40 ตร.ม. (ออกแบบทั้งห้อง)

### 1.5 อาคารพาณิชย์ / ตึกแถว (~5 entries)
- ตึกแถว 1 คูหา (4x12 ม., 2-3 ชั้น)
- ร้านค้า/ร้านกาแฟ fit-out
- สำนักงาน partition + ระบบ
- ตึกแถว renovate หน้าร้าน
- **ต่างจากบ้าน: โครงสร้างหนักกว่า, ระบบดับเพลิง, ลิฟต์**

### 1.6 โกดัง / โรงงานขนาดเล็ก (~3 entries)
- โกดังโครงเหล็ก 200-500 ตร.ม.
- โรงงานขนาดเล็ก + สำนักงาน
- **ต่างจากบ้าน: ไม่มีห้องน้ำเยอะ, โครงสร้างเหล็กแทนคอนกรีต, พื้น heavy-duty**

### 1.7 รั้ว / ภูมิทัศน์ (~3 entries)
- รั้วคอนกรีตบล็อก + เสาเข็ม
- รั้วเหล็ก/สแตนเลส + ประตูรั้ว
- ภูมิทัศน์ (ถมดิน, ปูหญ้า, ต้นไม้, ระบบรดน้ำ, ทางเดิน)

### 1.8 งานซ่อมแซมเฉพาะจุด (~3 entries)
- ซ่อมรั่ว (หลังคา/ดาดฟ้า/ท่อ)
- ซ่อมร้าว (ผนัง/เสา/คาน — วินิจฉัย structural vs superficial)
- ซ่อมระบบ (ไฟฟ้า/ประปา/แอร์)

### 1.9 สระว่ายน้ำ (~2 entries)
- สระคอนกรีตเสริมเหล็ก ขนาด 4x8 ม.
- สระไฟเบอร์กลาส (สำเร็จรูป)

## Phase 2: EzBOQ Business Module Knowledge (เพิ่ม ~20 entries)

### 2.1 PO — Purchase Order (~3 entries)
- Flow: BOQ → เลือกวัสดุ → สร้าง PO → ส่ง supplier → รับของ → ตรวจ
- PO ต้องมี: เลขที่, วันที่, supplier, รายการ, จำนวน, ราคา, เงื่อนไขชำระ
- การจัดซื้อ: รวม PO หลายโครงการ ประหยัดกว่า, ส่วนลดปริมาณ

### 2.2 Invoice / ใบวางบิลตามงวดงาน (~3 entries)
- แบ่งงวดมาตรฐาน:
  - บ้าน: 4-6 งวด (ฐานราก→โครง→หลังคา→ก่อฉาบ→ระบบ→ตกแต่ง)
  - ต่อเติม: 2-3 งวด
  - Interior: 2-3 งวด (วัสดุ 50% + ส่งมอบ 50%)
- % แต่ละงวด และเงื่อนไขส่งมอบ
- retention money (เงินค้ำประกันผลงาน 5%)

### 2.3 Contract / สัญญาว่าจ้าง (~3 entries)
- สัญญาเจ้าของ-ผู้รับเหมา (ข้อกำหนดหลัก 15+ ข้อ)
- สัญญาผู้รับเหมา-ช่าง (ผู้รับเหมาช่วง)
- penalty / ค่าปรับล่าช้า (0.01-0.1% ต่อวัน)
- ประกันผลงาน 1-2 ปี

### 2.4 Work Schedule / แผนก่อสร้าง (~3 entries)
- บ้าน 2 ชั้น: timeline 4-6 เดือน (ขั้นตอนไหนทำก่อน-หลัง)
- Critical path: ฐานราก → โครง → หลังคา → ก่อฉาบ → ระบบ → ตกแต่ง
- ต่อเติม: 1-2 เดือน
- รีโนเวท: 2-4 สัปดาห์ (ห้องน้ำ) / 2-3 เดือน (ทั้งหลัง)

### 2.5 Shop / การเปรียบเทียบราคา (~2 entries)
- วัสดุก่อสร้าง: บุญถาวร vs โฮมโปร vs ไทวัสดุ (ใครถูกกว่า?)
- เครื่องใช้ไฟฟ้า/แอร์: Lazada vs Power Buy vs ร้านแอร์
- เคล็ดลับ: ซื้อปลีก vs ซื้อส่ง, จังหวะโปรโมชั่น

### 2.6 Accounting / บัญชีผู้รับเหมา (~3 entries)
- Cash flow management: เงินรับตามงวด vs เงินจ่ายค่าวัสดุ+ค่าแรง
- ภ.ง.ด. 3 (หัก ณ ที่จ่ายจากช่าง) / ภ.ง.ด. 53 (จากบริษัท)
- กำไรมาตรฐาน: 15-25% (บ้าน), 20-35% (Interior), 10-15% (โครงสร้างใหญ่)
- overhead ค่าบริหาร: 5-10%

### 2.7 LINE Bot Integration (~2 entries)
- Use cases: ส่ง BOQ ให้ลูกค้าอนุมัติ, แจ้งงวดงาน, นัดตรวจงาน
- LIFF: แสดงเอกสารในแอพ LINE, ลงชื่ออนุมัติ

### 2.8 AI Jarvis Capabilities (~1 entry)
- สรุปสิ่งที่ Jarvis ทำได้: วิเคราะห์แบบ, คำนวณ BOQ, แนะนำวัสดุ, ออก PO
- Proactive alerts: วัสดุใกล้หมด, deadline ใกล้, ราคาเปลี่ยน

## Phase 3: Domain Expertise ลึก (เพิ่ม ~15 entries)

### 3.1 ค่าแรงช่างแยกประเภท (~3 entries)
- ค่าแรงช่างก่อ/ฉาบ, ช่างไฟ, ช่างประปา, ช่างสี, ช่างเหล็ก
- ค่าแรงเหมา vs รายวัน
- อัตราตามภูมิภาค (กทม. vs ต่างจังหวัด)

### 3.2 ใบอนุญาตและกฎหมาย (~3 entries)
- ขั้นตอนขออนุญาตก่อสร้าง (อ.1)
- ข้อกำหนด EIA/IEE (อาคารขนาดใหญ่)
- ประกันภัย (CAR insurance, ประกันอุบัติเหตุ)
- มาตรฐาน มยผ. (มาตรฐานก่อสร้าง)

### 3.3 การจัดการโครงการ (~3 entries)
- การบริหารงบ: ติดตามค่าใช้จ่ายจริง vs ประมาณการ
- Risk management: วัสดุขึ้นราคา, ฝนตก, ช่างขาดงาน
- QC checklist: ตรวจรับงานแต่ละขั้นตอน

### 3.4 ความรู้เฉพาะทาง (~4 entries)
- งานดิน: ถมดิน, บดอัด, เสาเข็ม (ต้องตอก vs เจาะ)
- งานกันซึม: วิธีทำ waterproofing ห้องน้ำ/ดาดฟ้า
- งานโครงสร้างเหล็ก: เชื่อม vs น็อต, ป้องกันสนิม
- งานระบบเปิด-ปิด: ประตูอัตโนมัติ, ระบบ smart home

### 3.5 มาตรฐานราคากลาง (~2 entries)
- ราคากลางงานก่อสร้างของราชการ (สำนักงบประมาณ)
- Factor F (ค่า overhead + กำไร + ภาษี สำหรับงานราชการ)

## Phase 4: Autonomy Engine Fixes (Code changes)

### 4.1 Quality Evaluator Fix
**ปัญหา:** Reviewer ให้ 5/10 ทุกครั้ง
**แก้:** ปรับ prompt ให้ evaluate ตามเกณฑ์ชัดเจน:
- มีราคาจริง? (+2)
- มีจำนวน/ปริมาณ? (+2)
- มีวิธีคำนวณ? (+2)
- ตรงกับ task? (+2)
- ไม่ hallucinate? (+2)

### 4.2 Task Decomposition
- ปรับ goal decomposer ให้แตก task ที่สอดคล้องกับ knowledge ที่มี
- ไม่สร้าง task ที่ต้อง web search (เพราะยังใช้ไม่ได้)

### 4.3 RAG Optimization
- เพิ่ม keyword index ให้ entry ใหม่ทุกตัว
- ปรับ search ให้ match category ด้วย (ไม่ใช่แค่ keyword)

## Phase 5: Testing & Validation

### 5.1 Knowledge Retrieval Test
- ทดสอบ search ทุก category → ต้องได้ผลลัพธ์ที่เกี่ยวข้อง
- ทดสอบ cross-category search (เช่น "ห้องน้ำ" → ได้ทั้งสุขภัณฑ์, กระเบื้อง, ประปา)

- สั่ง Goal: "สร้าง BOQ ต่อเติมห้องครัว" → ตรวจว่าใช้ราคาจริงจาก RAG

- วัด quality score ต้อง ≥ 7/10

### 5.3 End-to-End Validation
- ทดสอบครบ cycle: Goal → Decompose → Execute → Evaluate → Learn
- ตรวจว่า Gemma ไม่ hallucinate ราคา
